## Value Metric Analysis

### Primary Value Metrics (What Customers Pay For)

1. **Per-User Pricing** (Team, Enterprise, Strategic)
   - Aligns with team growth
   - Predictable scaling costs
   - Industry-standard model

2. **Per-Secret Usage** (Starter, Professional)
   - Pay for what you use
   - Appeals to cost-conscious segments
   - Potential upsell trigger

3. **Hybrid Model** (Optional)
   - Base fee + usage overage
   - Example: Team tier includes 500 secrets, $0.10/additional secret

### Secondary Value Drivers

- **Security features** (SSO, audit logs) → Enterprise+
- **Compliance certifications** → Enterprise+
- **Support SLAs** → Enterprise+
- **Customization** → Strategic only
- **Integration depth** → Progressive across tiers

## Packaging Principles

### Good Fences Make Good Neighbors

1. **Clear tier boundaries**: Each tier solves for a distinct job-to-be-done
2. **10× value jumps**: Each tier delivers ~10× more value than previous
3. **Non-overlapping personas**: Starter (solo) → Pro (power) → Team (dept) → Ent (org) → Strategic (custom)

### Feature Gating Strategy

**Hard Gates** (Cannot bypass without upgrade):
- User seats (enforced by system)
- SSO (not available in lower tiers)
- Audit log retention (auto-deleted)
- API rate limits (hard throttle)

**Soft Gates** (Can work around, but painful):
- Secret limits (can create new account)
- Integration limits (manual export/import)
- Support SLA (just slower response)

**Psychological Gates** (Status/perception):
- Branding ("Powered by OTS" badge on Starter)
- Priority support badge
- "Enterprise" label in UI

## Revenue Optimization Levers

### Primary Levers

1. **Price Increases** (5-10% annually)
   - Test on new customers first
   - Grandfather existing at renewal +3%
   - Communicate value adds

2. **Tier Compression** (Reduce Starter, push to Pro)
   - Lower Starter limits from 25 → 10 secrets
   - Make Professional the "recommended" tier

3. **Volume Discounts** (Seat expansion)
   - Lower per-seat cost at scale
   - Encourages org-wide deployment

4. **Add-On Revenue** (Beyond base tiers)
   - Premium integrations: $5-15/integration/month
   - Advanced analytics: $99/month
   - Priority support upgrade: $49/month
   - Additional storage: $10/100GB/month

### Secondary Levers

5. **Contract Length** (Annual prepay discounts)
   - 1-year: 15% off
   - 2-year: 25% off
   - 3-year: 30% off

6. **Bundling** (Multi-product)
   - Secrets + Password Manager: 10% bundle discount
   - Full suite: 20% discount

## Pricing Psychology & Anchoring

### Decoy Pricing

**Strategic Tier as Anchor**: $299/user makes $119 Enterprise seem reasonable

**Professional as "Goldilocks"**:
- Starter: $15 (too limited)
- Professional: $39 (just right) ← 60% choose this
- Team: $69 (too expensive for solo)

### Price Presentation

**Per-User/Month** (default):
- Team: $69/user/month
- Perception: Scales with usage

**Total Price**:
- Team (10 users): $690/month = $8,280/year
- Perception: Sticker shock, but justifiable

- Enterprise: $119/mo = $3.97/day
